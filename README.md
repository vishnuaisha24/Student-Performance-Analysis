# Student Performance Analysis

## Objective
Analyze student marks and attendance using Python, Pandas, Excel, and SQL.

## Files
- student_data.csv - sample dataset
- analysis.py - Python/Pandas analysis
- Student_Performance_Report.xlsx - Excel report and chart
- student_analysis.sql - SQL table, data, and analysis queries

## Tools
Python, Pandas, Microsoft Excel, SQL

## Skills Demonstrated
Data cleaning/handling, average calculation, performance categorization, basic data analysis, Excel reporting, SQL querying.
